Training & Courses

Build the skills before you apply.

These learning areas help applicants prepare for junior web development work and show evidence of sustainable design thinking.

HTML & CSS Foundations Semantic structure and responsive styling

Focus on semantic structure, responsive layouts, forms, navigation and maintainable stylesheet organisation.

  • Basic computer skills
  • Willingness to practise layout tasks
JavaScript Essentials Purposeful browser interaction

Learn DOM interaction, validation, progressive enhancement and how to keep scripts small and purposeful.

  • Confident with HTML forms and CSS selectors
  • Basic problem-solving skills
Sustainable Web Design Lower-impact digital design choices

Study image compression, page weight, performance budgets, accessibility and dark interface considerations.

  • Basic web design knowledge
  • Interest in low-carbon digital practice
Responsive Design Workshop Mobile, tablet and desktop layouts

Learn how to design and test layouts for phones, tablets and desktop screens using flexible grids and media queries.

  • HTML and CSS foundation skills
  • Access to a browser for testing
Web Accessibility Basics Inclusive pages and forms

Cover headings, alt text, colour contrast, form labels and keyboard navigation so websites work for more users.

  • Awareness of semantic HTML
  • Ability to review pages carefully
Git & Version Control Track, review and share code

Practise tracking changes, writing useful commit messages and working safely on shared website projects.

  • Basic command-line confidence
  • A small website project to practise with
Website Testing & Feedback Evidence-led improvements

Learn how to test functionality, compatibility and usability, then record changes made after user feedback.

  • Completed draft website or prototype
  • Access to at least two device sizes
Portfolio Project Build Prepare evidence for applications

Create a small recruitment-style website and document your design decisions, testing evidence and optimisation work.

  • Completed beginner HTML/CSS course
  • Interest in applying for junior roles

Portfolio Evidence

Applicants can strengthen their application by showing how they planned, built, tested and improved a website.

Design Notes

Include sketches, wireframes or explanations of how your design meets user needs.

Testing Evidence

Show device checks, browser testing, user feedback and improvements made after testing.

Optimisation

Record before-and-after changes such as image compression, cleaner CSS and improved loading speed.
