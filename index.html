About Hot Beans

We build websites that are practical, inclusive and efficient. Our teams keep page weight low, write purposeful code and test work across devices before launch.

Company Profile

Hot Beans Web is a growing web development company that supports clients with responsive websites, digital forms, content systems and accessibility improvements.

Sustainable Practice

Our developers reduce unnecessary requests, compress assets, avoid autoplaying media and choose semantic HTML so pages load faster and use less processing power.

Who We Hire

We welcome people who have completed web development courses or qualifications and want their first role in a supportive professional team.

Roles & Requirements

These entry-level roles are designed for new developers who can show curiosity, responsibility and a willingness to improve their craft.

Junior Web Developer

Build and maintain client pages using semantic HTML, efficient CSS and carefully chosen JavaScript.

  • Level 3 IT, web development or similar qualification
  • Understanding of responsive design and accessibility
  • Basic Git, HTML, CSS and JavaScript knowledge

Sustainable Web Trainee

Support performance checks, asset optimisation and sustainability improvements across existing websites.

  • Interest in low-carbon digital design
  • Ability to test pages on desktop and mobile
  • Clear communication and evidence of self-management
