Roles & Requirements

Start your web career with clear expectations.

These roles are suitable for applicants who have completed web development training and want to grow in a professional, sustainability-focused team.

Junior Web Developer Client pages, forms and responsive layouts

Work on client websites, page updates, forms and responsive layouts with support from senior developers.

  • Build semantic HTML pages from approved designs
  • Write efficient CSS for mobile and desktop layouts
  • Use JavaScript only where interaction requires it
  • Test pages for accessibility and usability issues
Sustainable Web Trainee Performance and sustainability checks

Support optimisation tasks and learn how to make websites faster, cleaner and easier to maintain.

  • Compress images and record file-size improvements
  • Check page load behaviour across devices
  • Document sustainability decisions for client handover
  • Help review pages against performance budgets
Frontend Accessibility Assistant Inclusive interfaces and navigation

Support accessibility improvements across client websites, forms and navigation systems.

  • Good understanding of semantic HTML
  • Ability to test pages with keyboard navigation
  • Awareness of colour contrast and readable content
  • Clear written notes for issues and fixes
Content & UX Trainee Readable journeys and useful content

Help organise website content so pages are easier to scan, understand and navigate.

  • Strong written communication
  • Interest in user needs and simple page journeys
  • Ability to improve headings, labels and link text
  • Basic understanding of wireframes or page plans
Website Testing Assistant Quality checks and test evidence

Test websites before launch and record evidence of functionality, compatibility, usability and sustainability checks.

  • Attention to detail
  • Ability to test on mobile and desktop browsers
  • Confidence completing test plans and test logs
  • Understanding of common website errors
Digital Support Trainee Client updates and support tasks

Support clients after launch by making small content updates, checking forms and reporting website issues.

  • Basic HTML and CMS editing confidence
  • Professional email communication
  • Good time management
  • Willingness to learn from client feedback

What We Look For

You do not need years of experience. We care about evidence that you can learn, communicate and take responsibility for improving your work.

Qualifications

Level 3 IT, web development, computing or equivalent portfolio-based training.

Technical Skills

Basic HTML, CSS, JavaScript, Git, responsive design and browser testing knowledge.

Professional Skills

Time management, clear communication, willingness to accept feedback and interest in sustainable practice.

Portfolio Evidence

One or two completed web pages showing planning, responsive design, testing and improvements.

Sustainability Awareness

Understanding of compressed images, efficient CSS, reduced JavaScript and avoiding unnecessary media.

Team Behaviours

Reliability, respectful communication, accountability and readiness to ask for help when needed.
